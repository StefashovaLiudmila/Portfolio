### [Анализ A/B-теста интерфейса интернет-магазина](ab_test_analysis/)  

Оценка влияния новой версии сайта на конверсию в покупку.  
- Проверка корректности теста (пересечения, баланс групп, мощность выборки)  
- Статистический анализ: z-тест для долей  
- Результат: конверсия выросла с 27.8% до 29.5%, p-value = 0.028 — различия статистически значимы  

Технологии: Python (pandas, numpy, scipy, statsmodels), matplotlib, seaborn, Jupyter Notebook.
